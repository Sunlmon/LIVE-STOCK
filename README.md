# LIVE STOCK / 活体滞销 — WIP 1

WIP 1 是第一阶段的视觉原型：用户先按 START，再尝试通过点击领养清空不断繁殖的动物。它包含六种原创 SVG 轮廓、Canvas 绘制、分批繁殖动画、点击粒子消散和屏幕饱和后的阶段占位画面。

## 运行

在项目根目录打开 PowerShell，运行：

```powershell
powershell -ExecutionPolicy Bypass -File .\serve.ps1
```

然后在浏览器打开 <http://localhost:8000>。停止服务器时，在终端按 `Ctrl+C`。

## 操作

点击 START 后，画面显示“清空屏幕”和“通过点击将小动物都领养出去”。点击动物尝试领养。繁殖时，动物先收缩并变黑；随后 4–6 个黑点从原位置向外散开，逐渐显现为同种幼崽。繁殖分批进行，以减轻瞬间生成大量动物造成的卡顿。达到饱和条件后，满屏动物会短暂停留，再渐隐显示“动物数量太多了，已经超越承受能力了”。

动物大小、繁殖间隔、每窝数量、数量上限和饱和阈值均可在 `src/config.js` 调整。本版本不包含 Matter.js、音频、最终结局统计或结尾动画。
