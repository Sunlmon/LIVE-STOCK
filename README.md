# LIVE STOCK / 活体滞销 — WIP 1

WIP 1 是第一阶段的视觉原型：尝试通过点击领养清空不断繁殖的动物。它包含六种原创 SVG 轮廓、Canvas 绘制、全局繁殖脉冲、点击粒子消散和屏幕饱和后的阶段占位画面。

## 运行

在项目根目录打开 PowerShell，运行：

```powershell
powershell -ExecutionPolicy Bypass -File .\serve.ps1
```

然后在浏览器打开 <http://localhost:8000>。停止服务器时，在终端按 `Ctrl+C`。

## 操作

点击“开始”，然后点击动物尝试领养。画面每隔一段时间触发一次繁殖脉冲；脉冲开始时仍在屏幕上的动物播放短暂压缩动画，之后各生成 4–6 只同种动物。新生动物从下一轮脉冲开始参与繁殖。动物达到数量或密度阈值后，原型自动切换到 WIP 2 占位画面。

动物大小、繁殖间隔、每窝数量、数量上限和饱和阈值均可在 `src/config.js` 调整。本版本不包含 Matter.js、音频、最终结局统计或结尾动画。
